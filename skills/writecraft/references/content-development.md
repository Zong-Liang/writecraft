# 内容构建与结构设计

## 从用途确定覆盖与组织

先判断读者怎样使用文档，以及交付必须覆盖什么。材料中的篇幅和排列顺序不代表重要程度；模板、规范、任务要求和使用需要共同决定覆盖范围。下表用于选择处理方式，可按章节组合，不是固定目录或穷尽的文种清单。

| 内容用途 | 组织依据 | 重点检查 |
| --- | --- | --- |
| 呈现事实与状态 | 对象、时间、指标、状态 | 口径一致；已完成、进行中、计划与待确认分清。 |
| 记录与留存 | 时间、议题、来源、决定 | 过程、分歧与归属可追溯；记录与事后解释分清。 |
| 解释机制 | 概念依赖、组成、关系、例子 | 读者能理解对象如何运作及其条件。 |
| 教学与训练 | 已有知识、学习步骤、示例、练习与反馈 | 支持能力形成；允许有作用的解释与重复。 |
| 指导执行 | 场景、前提、步骤、分支、验证 | 操作可实施，成功、失败和停止条件清楚。 |
| 支持查阅 | 对象分类、稳定字段、索引与交叉引用 | 条目准确完整，便于定位并独立使用。 |
| 定义与约定 | 概念、范围、责任、规则、例外 | 表述可判定，定义一致，条目不互相矛盾。 |
| 方案与决策 | 目标、约束、共同标准、取舍与实施 | 比较公平，建议有依据，代价与条件明确。 |
| 研究与知识贡献 | 研究问题、材料或方法、结果、解释 | 各部分对应，贡献与证据相符，满足适用要求。 |
| 分析与评价 | 命题、评价标准、依据、推理与异议 | 推理成立，关键反例得到处理。 |
| 协调与关系 | 事项、双方关系、所需回应 | 接收者理解事情和请求，语气适合情境。 |
| 介绍与说服 | 受众关切、价值、依据与行动 | 吸引力有内容支撑，承诺不超出材料与授权。 |
| 叙事与个人表达 | 视角、事件、细节、情绪与节奏 | 保留声音；真实经历不补造，细节服务表达。 |
| 界面与短内容 | 当前状态、上下文、可采取的行动 | 在空间和媒介限制下准确、清楚、可理解。 |

明确要求创意或虚构写作时，按创作意图、形式与设定处理；不能把专业文稿的论证要求强加给虚构叙事。遇到未列举的文种，结合实际用途、使用方式和约束选择标准。

例如，一份技术设计可以同时包含审批摘要、架构解释、接口定义和迁移步骤。各部分承担不同职责，整体检查设计关系、术语和状态是否一致。需要保留的接口字段或异常分支，不以是否支持摘要中的判断来决定去留。

## 组织材料与分配详略

辨认材料中的事实、作者观点、证据、推断、假设、约定与待办，以及它们的支持、依赖、先后、并列或冲突关系。按用途组织，而不是逐份来源复述。

- **论证内容**：明确主要问题及材料能支持的回答，选择关键依据；保留会改变判断的反例和条件。
- **多目标专业材料**：检查必需对象、字段、流程和分支是否覆盖，区分总体说明与局部细节。无需给每个部分制造共同论点。
- **记录与摘要**：保留所需的决定、理由、分歧、负责人和时点。提议不能压缩成决定，未表态不能写成一致同意。
- **叙事与表达**：从已有材料中选择能呈现人物、处境或感受的细节，安排视角与节奏；不为增强感染力补造经历。

重要内容获得相应篇幅，辅助材料可进入附录或被准确引用。压缩前检查删去的信息是否承担必需覆盖、复核、执行或表达作用。关键负面结果、限制条件和来源不能为得到更整齐的故事而省略。

材料互相冲突时，先判断是否来自不同时间、版本、对象或统计口径。依据充分时区分适用范围；否则具体指出冲突及其影响，不默认较新或措辞更确定的一份必然正确。材料中的未知内容不得为了填满模板而虚构。

## 构建解释与论证

解释内容补足对象、机制、状态变化与条件；论证内容检查依据为何能够支持判断。以下用于新写内容或允许实质性编辑的任务；纯语言修改遵循入口的授权边界。

| 遇到的问题 | 处理方式 |
| --- | --- |
| 证据与结论之间缺少前提 | 补充有依据的前提与推理，或收窄结论。不能只添加“因此”制造因果。 |
| 观察结果有多种解释 | 区分观察与解释，处理会影响结论的其他解释；必要时指出能区分它们的新证据。 |
| 方案比较标准不一致 | 在与目标相关的共同维度下比较，说明必要的取舍与条件。 |
| 关键事实可查证 | 优先查原始资料，把来源放在所支持的内容附近，按需注明版本、样本或日期。 |
| 关键事实暂时无法确认 | 完成不受影响的部分，具体指出缺口；依赖该事实的判断保持条件化或待验证状态。 |

例如，“操作步骤减少”支持流程变短；要推出“错误率降低”，还需要相应的错误来源分析或观察依据。方法 X 在数据集 A 的指标 M 上高于基线 B，只支持相应设置下的表现；是否能推广取决于额外证据和使用要求。

处理反例是为判断服务，不要求每篇文章机械列出正反两面，也不对证据强弱悬殊的观点分配相等篇幅。

## 专业与学术内容

按实际任务采用用户提供的模板、目标期刊要求、组织规范或领域约定。需要核实当前要求时查原始来源；未获得依据时，不声称已经满足某项规范。规范中的必要条目不能因通用的简洁偏好被删除。

- **设计、规格与规则**：区分当前行为、目标设计与建议。核对定义、主体、条件、例外、接口和验收方式；措辞变化不得意外改变义务或必选程度。
- **操作与参考材料**：只使用已知的命令、参数和环境条件。执行入口说明必要前提；查阅条目保留局部使用所需的信息或准确引用。不要猜测未提供的恢复命令。
- **研究写作**：结合研究类型选择结构。实证研究关注问题、设计、结果与解释；理论研究关注定义、前提与推导；方法或系统研究关注设计、评价与代价；综述关注范围、材料选择、分类与综合。类型可交叉，不强套固定章节。
- **贡献与完整报告**：说清相对已有工作的具体新增内容。“首次”“填补空白”“显著优于”等表述需要相应依据。区分预期、观察和解释，保留影响研究判断的负面结果、无显著差异结果、方法限制及复核信息。
- **学术一致性**：检查摘要、正文、图表和结论的口径是否一致，研究问题是否得到回应，结果是否被解释过度。没有统计依据时，不把一般差异改写为统计显著；不得补造样本、分析、引文或实验。

## 阅读路径与段落关系

- **通读**：按概念依赖解释前置知识。检查相邻段落是在解释、证明、具体化、修正前文，还是进入下一个必要部分；关系缺失时先补推理或调整顺序。
- **查阅**：按对象与使用入口组织，条目可独立理解。必要条件可以在多个独立条目中重复；跨引用应指向具体内容，不能让读者反复跳转才能完成简单任务。
- **操作**：将前提和关键限制放在动作之前，验证放在相应操作之后；区分正常路径、异常路径和停止条件。
- **学习**：考虑读者已有知识，给出可理解的示例、适当练习和反馈；重复有助于巩固时保留。示例与练习不能假装成实际实验结果。
- **听讲与浏览**：按媒介控制信息密度，为关键关系提供必要提示；细节可按任务要求放入补充材料。

连续论述检查每段新增的理解或表达作用；独立条目检查自身完整与同类一致。叙事中的场景、节奏和情绪也是有效作用。连接词、段落数量和句长都不应成为机械指标。

例子、类比、图表或流程用于解决具体的理解障碍。类比保留与解释有关的对应关系，不能代替技术定义；两种形式各有作用时可以并存，无需为了避免重复强行删掉一种。

## 标题与全文一致性

标题准确标识内容，语气符合文体。正式材料优先交代对象、范围与用途；教程可使用真实问题；个人文章可保留有作用的意象或修辞。编辑时保留合适的原题，遵守既有目录要求。

同级标题与分类使用一致口径，职责重叠时先调整内容边界。检查标题是否覆盖正文，不能用更强的标题夸大正文结论。

全文复查术语、数值、版本、时间、角色和完成状态是否一致，正文与附录、摘要与细节、表格与解释是否相互对应。专业内容的完整与一致、连续论述的推进、叙事的节奏，分别按其用途检查。
