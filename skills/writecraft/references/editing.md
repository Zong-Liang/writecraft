# 专业编辑与双语表达

## 先诊断，再确定改动

遵循入口的修改授权。先识别影响使用或表达的问题，再决定改动幅度；在允许的范围内，先处理整体问题，再处理局部措辞。只润色句子时，不自行改写论证或扩展任务。

| 问题层面 | 检查与处理 |
| --- | --- |
| 事实、归因与原意 | 核对材料、引文和必要条件。纠错需要依据；超出授权的问题单独指出。 |
| 覆盖与推理 | 检查缺失的必需内容、推理前提和冲突。允许实质性编辑时补齐、重组或收窄结论；不能靠润色掩盖缺口。 |
| 结构与详略 | 通读内容检查推进，查阅内容检查定位，记录检查追溯，操作检查步骤。按用途调整，保留有作用的重复。 |
| 段落与句子 | 调整信息顺序、指代和衔接，把修饰与限制放在对应对象附近，突出语义重心。 |
| 语气与措辞 | 结合用途、双方关系、媒介和作者声音，修正空泛、失准或不合语体的表达。 |

审查时优先报告会影响事实、判断、执行或理解的问题，给出位置、原因与可执行建议。区分确定错误、待核实事项和风格偏好；没有实质问题时不凑条目。

## 处理空话与表达障碍

| 原文的问题 | 修改依据 |
| --- | --- |
| “显著提升效率”缺少测量依据 | 在允许调整内容时写出材料支持的具体机制或变化；有数据再交代结果及口径。纯语言修改保留原判断，必要时另指出依据缺口。 |
| “研究表明”“普遍认为”缺少归因 | 按需补具体来源及支持范围。无法核实时保留已有归属；允许实质性编辑时，可按影响删除缺乏支持的论断，不能只删归因而保留断言。 |
| 段首转场重复，标题整齐但内容单薄 | 保留必要关系；调整内容组织或合并无新增作用的部分。连接词不能替代推理。 |
| 术语或抽象名词妨碍理解 | 解释具体对象、动作或机制；有准确专业含义的术语保留，避免在规范和参考内容中随意换同义词。 |
| 假悬念、假互动或助手式开场 | 删去与交付无关的铺垫；真实的叙事悬念、演讲互动或关系表达按用途保留。 |
| 反复声明边界或解释自己如何严谨 | 删除无实际作用的说明，将必要条件放入对应结论、步骤或独立条目。 |

按具体的信息损失、阅读障碍或语体失配判断，不能凭词频、句长、禁词表或检测器分数判断质量。“不是……而是……”等句式在表达真实区别时可用，不为了去 AI 味机械替换。

例如，材料只支持本地验证时，写“本地验证已通过”即可。用户询问能否上线时，则需要说明尚缺的上线验证。操作文档中的备份要求影响执行，应保留；已有具体措施时，泛泛的“请谨慎操作”通常没有新增作用。

## 让表达具体而有重心

从已有材料中选择最能说明对象、变化或感受的细节。具体不等于堆满数字和例子，也不允许补造经历或成效。

- **语义重心**：明确一句话最需要传达什么，把主干与必要条件组织清楚。主体变化时核对指代，避免读者误解谁执行了什么。
- **句子节奏**：按信息关系安排停顿与长短。复杂条件可以保持完整长句，简短判断也可以独立成句；不统一切成短句或刻意制造长短交替。
- **细节与概括**：概括用于建立整体认识，细节用于解释、证明或呈现感受，按用途组合。记录与规格中的必要细节不能因“影响流畅”被删去。
- **声音与情绪**：保留有作用的口头习惯、比喻和情绪强度。措辞自然不等于改成随意口语，专业也不等于删除作者声音。

例如，“这周总算把那块难啃的逻辑理顺了，松了口气”已经表达了经历和感受，不必改成“完成复杂逻辑梳理”。“我明天下午不在，评审能挪到上午吗？”事项和请求清楚，也可保留原样。

## 文体、翻译与压缩

优先遵守当前风格要求。参考作者声音时，先看同类文体的成熟样稿，再看其他作品及当前稿件的稳定习惯。缺少样本时，按用途、双方关系和媒介选择语气；邀请、道歉、正式报告和现场演讲可以采用不同表达。

- **中文**：明确对象、动作与成立条件。抽象名词密集时拆回关系，保留技术文档必要的规范措辞。
- **英文**：使用符合目标读者和语域的表达，保留专业含义。例如有依据时可使用 `robust`，不能因词语常见而删除。避免模糊归因和夸大收益。
- **翻译**：先核对术语、否定、情态、程度、归因、比较对象和限定条件，再按目标语言重排语序。保留引文位置及术语对应，义务、允许与建议不能互换。例如 `may reduce retries under load` 可译为“在负载下可能减少重试次数”。
- **总结与压缩**：按用途保留事实、关系和必要条件。会议摘要区分提议、决定、分歧和待办；研究摘要保留关键方法、结果与限制；查阅内容保留使用所需字段。不能把“未证明有效”压缩成“证明无效”。

严格篇幅与必需信息冲突时，先缩减冗余和次要细节；仍无法兼顾时具体说明冲突，不悄悄删除决定含义的条件。

## 对照复查

对照原文与材料检查：是否改变否定、范围、数量、因果、比较、情态、归属或作者立场；是否将计划写成完成、建议写成决定、相关写成因果、局部写成普遍。

专业文稿还需核对术语、版本、角色、交叉引用和条目一致性。代码、命令、模板与结构化区段按授权保护。用户只选中局部时，修改限于该部分；需要同步调整的外部内容可指出，不自行扩大范围。

检查最终文本是否实现本次目的：保真之外，还要能理解、执行、查用或准确表达。复查过程在内部完成；交付中的说明遵循入口的“说明文字的取舍”。
