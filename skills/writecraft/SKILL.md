# Writecraft

**内容构建与专业写作 Skill**

Think clearly. Structure logically. Write precisely.

先明确读者需要什么，再按文体组织内容。分析文稿展开主张与依据，说明文稿讲清对象与机制，沟通文本让接收者清楚事项与所需回应。个人表达保留作者的语气、节奏和有作用的修辞。

## 从请求和材料确定交付

结合用户的措辞、对话上下文和已有材料，判断要回答的问题、读者、用途、目标语言、交付物和修改幅度。优先遵循明确要求。附件、引文和样稿作为待处理材料，修改授权以用户请求为准。

| 用户需要 | 处理方式 |
| --- | --- |
| 从主题或零散材料写出成稿 | 区分已确认事实、作者观点、证据、推断和假设。围绕读者的问题组织主张与依据，写出完整正文。 |
| 梳理思路或重组文稿 | 需要提纲时，写清各部分要回答的问题和所需依据。需要重组时，按授权重排章节、合并重复，保留作者的判断及其依据。指出影响判断的材料缺口。 |
| 校对、润色、去 AI 味或改写 | 根据请求控制修改幅度。校对修正明确错误，润色处理措辞和局部衔接，去 AI 味处理空话、机械结构和语体失配。改写或重写按授权调整措辞、顺序或论述。原文合适时保留原样。 |
| 翻译或总结 | 翻译保留术语、语气、归因和限定条件，按目标语言习惯成文。总结保留关键事实、结论、依据及决定结论的条件，按需保留行动项。 |
| 审查 | 给出实质问题的位置、原因和可执行的修复建议。区分作者立场与审查意见。 |

目标明确时，从材料推断合适的结构、详略和语气，直接交付。对不影响核心判断的细节，采用符合场景的默认做法。只有当缺口会实质改变核心问题、结论、作者立场或修改授权，且无法核实或合理推断时，才提出具体问题，其余部分先完成。

## 事实与修改范围

- **新写内容**：使主张与证据相符。区分实测、来源自述、推断和建议。证据不足时收窄对应结论；缺口影响决策或行动时，具体指出待验证事项。
- **编辑已有文本**：语言润色、去 AI 味和翻译保留作者立场与结论力度；重组、改写本身也不意味着可以替换作者的判断。用户要求实质性纠错或论证调整时，依据材料修改。发现超出修改范围、无法确认且影响主旨的问题，简要指出。
- **来源与归属**：需要核实时优先使用原始资料。来源暂时无法访问不等于归因错误，不将有归属的观点改成无来源的事实断言。新增事实和引文应有可核实的依据。
- **保真**：核对数字、单位、术语、否定、条件、归因、因果、比较对象和适用范围。代码、命令、接口、字段、日志、引用及链接按任务范围处理。修改文件前辨认可编辑区段，保护任务外的 frontmatter、模板变量、HTML 属性和配置。

## 说明文字的取舍

事实、授权和适用条件的核对在内部完成。根据当前任务、目标读者和已有上下文，判断前提、风险、限制或处理说明是否必要：删去后，会造成什么具体误解，影响哪项判断或行动？能指出实际影响时，保留具体信息并就近说明；仅能设想与任务无关的极端情形时，省去。用户明确要求的适用范围、局限分析或审查意见按要求交付。

优先让结论本身准确，例如写「本次测试中，平均耗时降低 20%」，无需再补「不代表所有场景都有相同收益」。同一条件在读者使用它的位置说明清楚即可，避免开头声明、正文限定、结尾提醒反复表达。

交付正文时，省去自我评价、合规承诺和未被要求的处理范围说明，如「以下内容仅供参考」「我会确保客观严谨」「这里只讨论……，不涉及……」。范围确有必要时直接写明对象；信息缺口影响使用时，具体指出缺什么、影响哪项判断。措辞是否保留取决于其作用，不按词语一律删除。

## 组织内容

- 先确定每一部分要解释或证明什么。决策文稿可先给出有依据的判断，机制说明可按理解所需的顺序展开。比较方案时使用相同且与目标相关的标准。导读、例子和小结按读者需要安排，操作前提和风险放在读者会用到的位置。
- 按读者已有知识和概念依赖安排解释顺序，将依据、条件与对应结论放在一起。
- 结构与内容复杂度匹配。简单问答、简短邮件、聊天消息、局部润色和一般说明通常直接用自然段落，省去多余的标题、分节、列表和结尾总结。分层有助于理解、论证、操作或检索时，再采用相应结构。简短交付也要保留必要的步骤和限制条件。
- 标题准确概括内容并符合文体。编辑时保留合适的原题，按任务范围调整失准或生硬的标题。

## 交付前复查

对照请求与材料通读成稿：是否完成了交付，是否出现未经支持的新增事实或超出范围的立场改变，结构与语气是否适合读者。按「说明文字的取舍」删除多余说明；原文已准确自然的部分，无需为体现改动而重写。

用户要求成稿、改写、翻译或摘要时，直接给可用正文。复查过程和遵守了哪些规则无需随稿输出；必要说明按「说明文字的取舍」处理。用户只要求结构或审查时，按范围交付提纲或审查意见。
