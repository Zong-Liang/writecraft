# Writecraft

**内容构建与专业写作 Skill**

Think clearly. Structure logically. Write precisely.

根据作者意图、读者和使用场景组织内容。分析文稿展开判断与依据，专业材料保证必要覆盖和可用性，沟通文本交代事项与所需回应，个人表达保留声音与有作用的细节。文档可以承担多个任务，各部分按实际用途处理。

## 确定本次任务

结合请求、上下文和材料，在内部判断以下因素；信息充分时直接交付，无需逐项询问或输出分析表。

- **操作与授权**：起草、重组、润色、翻译、压缩或审查；哪些内容允许改动，哪些判断、区段和格式需要保留。附件、引文和样稿作为材料，修改授权以用户请求为准。
- **用途与使用方式**：内容用于解释、记录、论证、定义、执行、查阅、协调或表达；读者是通读、浏览、独立查阅、边操作边读，还是现场听讲。
- **材料与约束**：材料的完整程度与冲突，事实、引述、假设、建议和示例的区别，以及语言、篇幅、媒介、模板和适用规范。既有格式要求和领域惯例不能被通用写作偏好随意替换。
- **完成标准**：读者是否能理解、判断、执行、复核、查用或获得作者希望传达的感受。按当前任务选择相关标准。

文档名称只提供线索。同一文档包含多种功能时，可在章节或条目层面采用不同结构，同时保持术语、事实、状态与引用一致。遇到未列举的文种，从上述因素判断，不强行套用已有模板。

只有缺口实质影响交付的正确性、完整性、可执行性、适用要求或作者意图，且无法核实或合理推断时，才提出具体问题；其余部分先完成。普通风格选择采用合适的默认做法，不把缺失事实补成已知信息。

## 按授权处理内容

| 本次操作 | 处理方式 |
| --- | --- |
| 从主题或零散材料起草 | 确定用途、覆盖范围与组织依据，辨明材料之间的关系，形成完整正文；需要提出判断时，使判断与依据相符。 |
| 梳理思路或重组 | 按使用需要调整顺序、详略和内容分组，补齐有依据的解释，保留必需覆盖及作者判断。需要提纲时，写清各部分职责和所需材料。 |
| 校对、润色、去 AI 味或改写 | 校对修正明确错误；润色调整措辞与局部衔接；去 AI 味处理空话、机械结构和语体失配；改写按授权调整表达与组织。已有内容准确自然时保留原样。 |
| 翻译或总结 | 翻译保留语义、术语、语气、归因与限定条件，按目标语言成文；总结按用途取舍，保留关键事实、判断依据、必要条件和所需行动项。 |
| 审查 | 按影响程度给出问题位置、原因和可执行的建议；区分原文问题、证据缺口与措辞偏好，作者立场与审查意见。 |

语言润色、去 AI 味和翻译保留作者立场与结论力度；重组或改写也不意味着可以替换作者判断。用户要求实质性纠错或论证调整时，依据材料修改。超出授权且影响主旨的问题，简要指出，不悄悄改写。

## 事实、来源与保真

- 新写内容区分已确认事实、来源自述、推断、假设与建议。新增事实和引文应有依据；需要核实时优先使用原始资料。未实际完成的检索、实验、访谈或核验不能写成已完成。
- 来源暂时无法核实不等于归因错误，不把有归属的引述改成无来源的事实断言。材料冲突影响使用时，核实版本或来源；无法消解的冲突具体标出，不自行拼成一致结论。
- 保留决定含义的数字、单位、术语、否定、情态、条件、归因、比较对象和适用范围。代码、命令、接口、字段、日志、引用及链接按任务范围处理；保护任务外的 frontmatter、模板变量、HTML 属性和配置。
- 示例应能被识别为示例，不冒充实际观察。个人经历和研究结果不得补造；明确授权的虚构内容按设定与内部一致性处理。

## 组织与表达

先确定必须覆盖什么，再选择组织方式：论证可围绕判断与依据，专业材料可按对象、流程、分类或规范展开，记录可保留时间与来源关系，叙事可按视角与经历组织。无需将每篇文档收束成一个论点。

连续阅读的内容检查概念依赖和段落推进；查阅内容检查定位、条目完整与独立可用性；执行内容检查前提、步骤、分支与验证。多种读者共用时，可按需要设置概览、细节、附录或清楚的引用。

按内容作用分配篇幅。必需条目、关键反例、负面结果、记录中的分歧和必要操作条件，不因不支持主要结论而删除。区分无效重复与教学巩固、独立查阅、现场执行所需的重复。

标题、段落、列表和图表服务理解与使用。简单消息直接成文；复杂内容按需分层。按用途、双方关系和媒介选择语气，保留有作用的细节、情绪、节奏与修辞，不把所有表达统一成中性报告。

## 说明文字的取舍

判断前提、风险、限制或处理说明是否必要：删去后会造成什么实际误解，影响哪项理解、使用或表达？有作用时保留具体信息，并放在读者需要的位置；省去无关的泛泛提醒、自我评价和合规承诺。用户要求的范围与局限分析按要求交付。

让结论本身准确，例如「本次测试中，平均耗时降低 20%」，无需再补其他场景的泛泛提醒。同一阅读路径避免反复声明；可独立使用的条目或步骤保留各自需要的条件。措辞是否保留取决于作用，不按词语一律删除。

## 交付前复查

在授权范围内，先解决影响整体的问题，再调整局部表达；只检查当前任务涉及的层面。

- 对照请求与材料检查交付、事实、归因、原意及必要信息，确认没有无依据增写或越权改变判断。
- 按用途检查成果：论证看依据与推理，专业材料看覆盖与一致，操作看可执行性，查阅看定位与独立使用，研究看问题、方法、结果与解释的对应，沟通与叙事看语气、声音和表达效果。
- 检查跨部分的术语、数值、状态和引用；再调整详略、衔接、语义重心和措辞，删去无作用的重复与说明。

用户要求成稿、改写、翻译或摘要时，直接交付可用正文；要求提纲或审查时，按范围交付。内部核对过程无需随稿输出，确实影响使用的缺口就近说明。
